# Student Performance & Placement Analytics

## 📌 Project Overview

Student Performance & Placement Analytics is a Python-based data analysis project that analyzes student academic performance, skills, attendance, projects, internships, and placement outcomes.

The project uses NumPy and Pandas for data generation, data cleaning, analysis, and aggregation, along with Matplotlib for data visualization.

---

## 🎯 Objectives

- Analyze student academic performance
- Study factors associated with placement outcomes
- Compare placed and non-placed students
- Analyze department-wise placement rates
- Analyze the relationship between CGPA and package
- Identify top-performing placed students
- Visualize important placement statistics

---
